# 週次記事生成スキル

## 概要
毎週1回、動物園・生物・自然環境に関する記事ドラフトを自動生成する。
生成後、インフォグラフィックと参考URLを自動で付与する。
Zoo Knowledge Vault のルートディレクトリで実行すること。

## ステップ 1: カテゴリの決定

現在の週番号を取得し、5週ローテーションでカテゴリを決定する:

```bash
WEEK=$(date +%V)
CATEGORY_NUM=$((10#$WEEK % 5))
```

| 週番号 % 5 | カテゴリ | 保存先フォルダ |
|-----------|---------|--------------|
| 1 | 飼育日誌 | `01_飼育日誌/` |
| 2 | 季節トピック | `02_季節トピック/` |
| 3 | 飼育ノウハウ | `03_飼育ノウハウ/` |
| 4 | 生態系ニュース | `04_生態系ニュース/` |
| 0 | 自然環境 | `06_自然環境/` |

## ステップ 2: 既存記事のスキャン

重複を避けるため既存記事タイトルを収集:

```bash
find ./01_飼育日誌 -name "*.md" | xargs grep -h "^title:" 2>/dev/null | sort
```

## ステップ 3: 記事生成ルール

### 共通ルール
- フロントマター（YAML）を必ず含める
- 1記事あたり1500〜3000字
- 専門用語には平易な説明を併記
- 最低3つのウィキリンク（`[[記事名]]`）を含める
- 画像の代替として、表やリストで情報を整理
- 読者は飼育員・動物園関係者を前提に、実務に役立つ具体的な情報を優先する

### フロントマター形式
```yaml
---
title: "[生成した記事タイトル]"
date: [生成日 YYYY-MM-DD]
updated: [生成日 YYYY-MM-DD]
tags:
  - [カテゴリタグ]
  - [関連タグ1]
  - [関連タグ2]
author: "Zoo Knowledge Vault"
draft: true
---
```

### カテゴリ別ルール

#### 飼育日誌
- 特定の動物種の実際の飼育で起こりうる場面を描写
- 観察のポイント、判断基準、対応策を具体的に記述
- タグ: `#飼育日誌` + 動物分類タグ

#### 季節トピック
- 現在の季節に合わせる
- 飼育管理上の注意点を必ず含める
- タグ: `#季節トピック` + 季節タグ

#### 飼育ノウハウ
- 手順を段階的に記述・必要器材を明記・安全管理を含める
- タグ: `#飼育ノウハウ` + 専門分野タグ

#### 生態系ニュース
- 最新の保全・環境ニュースを解説
- 動物園として何ができるかの視点を含める
- タグ: `#生態系ニュース` + 関連タグ

#### 自然環境
- 特定の生息地・生態系の解説
- タグ: `#自然環境` + 関連タグ

## ステップ 4: ファイルの保存

```
ファイル名: _drafts/[カテゴリ略称]_[YYYY-MM-DD]_[タイトルの一部].md
```

## ステップ 5: インフォグラフィック生成（自動）

記事保存後、以下のコマンドでインフォグラフィックと参考URLを自動生成する:

```bash
python3 .claude/generate_infographic.py "_drafts/[生成した記事ファイル名].md"
```

処理内容:
1. **インフォグラフィック生成** — Gemini API で記事内容からSVG形式のインフォグラフィックを生成
   - 自然・動物・植物テーマの配色（森林グリーン系）
   - タイトル・主要ポイント3〜4件・アイコンを含む
   - `_images/[タイトル]_infographic.svg` に保存
   - 記事冒頭（フロントマター直後）に自動挿入

2. **参考URL自動収集** — 記事トピックに関連する信頼性の高い参考URLを収集
   - JAZA・環境省・大学研究機関などを優先
   - 記事末尾の「## 参考・引用元」セクションに自動挿入

## ステップ 6: 完了確認

- 生成したファイルのパスを表示
- インフォグラフィックの生成結果を確認
- 品質チェックを案内:
  「`/article-quality-check` で品質チェックができます」
